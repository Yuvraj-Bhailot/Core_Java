# ☕ Core Java

A beginner-friendly **Core Java** repository that covers Java fundamentals through simple, easy-to-understand programs. This repository is designed for students and developers who want to build a strong foundation in Java by learning concepts along with basic coding examples.

## 📌 About

This repository contains categorized Java programs that explain Core Java concepts from the basics to intermediate topics. Each topic is accompanied by simple programs to help understand the concepts practically.

## 🎯 Objectives

- Learn Core Java from scratch.
- Understand Java concepts with hands-on programs.
- Build a strong foundation before moving to frameworks like Spring Boot.
- Practice interview-oriented Java concepts.

---

# 📚 Course Structure

## 🌱 Season 1 – Java Fundamentals

Learn the building blocks of Java programming.

- Introduction to Programming Language
- History of Java
- JDK, JRE, JVM & JIT Compiler
- Structure of Java Program
- Command Prompt (CMD)
- Java Tokens
- Data Types & Variables
- Operators
- Type Casting
- Dynamic Input (Scanner Class)
- Decision Making Statements
- Looping Statements
- Number Programs
- Methods

---

## 🚀 Season 2 – Object-Oriented Programming (OOP)

Understand the core OOP principles and Java object model.

- Static
- Static Members
- Class Loading Process
- Object
- Non-Static
- Non-Static Members
- Object Loading Process
- Constructors
- Constructor Overloading & Constructor Chaining
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interface

---

## 💻 Season 3 – Java Implementation Concepts

Explore commonly used Java classes and implementation concepts.

- Arrays
- Object Class
- String
- Wrapper Class
- Exception
- Exception Handling

---

## 🔥 Extra Topics

Take your Java knowledge to the next level.

- Collections
- Multithreading
- File Handling

# ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/<your-username>/Core_Java.git
```

2. Open the project in your preferred IDE.

3. Navigate to any topic folder.

4. Compile the Java file:

```bash
javac FileName.java
```

5. Run the program:

```bash
java FileName
```
