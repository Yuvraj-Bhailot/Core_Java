# Introduction to Java

## What is a Language?

A language is a medium used to communicate with others.

## What is a Programming Language?

A programming language is a set of instructions used to communicate with a computer or system.

Programming languages are mainly classified into three types:

1. Low-Level Language
2. Mid-Level Language
3. High-Level Language

## 1. Low-Level Language

* Low-level language is also known as machine-level language.
* Computers understand instructions in the form of binary numbers, `0` and `1`.
* It is easy for a machine to understand but difficult for humans to write and understand.

## 2. Mid-Level Language

* Mid-level language is also known as assembly-level language.
* It uses predefined words called **mnemonics** to represent instructions.
* Examples of mnemonics include `ADD`, `SUB`, and `MUL`.
* It is more understandable than machine language but is not suitable for developing large and complex applications.

## 3. High-Level Language

* High-level languages are easier for programmers to read, understand, and write.
* They can be used to develop different types of applications and games.
* Examples include Java, C, C++, C#, Python, and Ruby.

## Source File

A source file is a file that contains instructions written in a high-level programming language.

A Java source file has the `.java` extension.

## Compiler

A compiler is software that converts high-level language instructions into a lower-level or machine-understandable form.

## Interpreter

An interpreter converts and executes instructions one by one.

## History of Java

* Java was developed by **James Gosling**.
* Java was introduced in **1995**.
* Java is used to develop various types of applications, including web, business, standalone, and mobile applications.

## Features of Java

Some important features of Java are:

* Easy and Simple
* Platform Independent
* Object-Oriented
* Highly Secure
* Portable
* High Performance
* Multithreaded
* Robust

## Platform Dependent

A platform-dependent application can execute only on the specific platform or system for which it was developed.

The generated executable file depends on the system configuration.

## Platform Independent

A platform-independent application can run on different platforms.

Java source code is compiled into an intermediate code called **bytecode**. The bytecode can run on different platforms using the appropriate Java Runtime Environment.

Therefore, Java is known as a **platform-independent language**.

## Java Source File

A Java source file contains instructions written in Java.

* Extension: `.java`

## Java Compiler (`javac`)

`javac` stands for **Java Compiler**.

It compiles a Java source file and generates bytecode.

## Bytecode

Bytecode is an intermediate code generated by the Java compiler.

* Extension: `.class`
* It is not directly understandable by the programmer or the machine.
* It is executed by the Java Runtime Environment.

## Ways to Create a Java Source File

A Java source file can be created using:

1. Editors
2. IDEs

## Editors

Examples:

* Notepad
* Notepad++
* EditPlus

When using a basic editor, the command prompt is generally used to compile and execute the Java program.

## IDE

IDE stands for **Integrated Development Environment**.

Examples:

* Eclipse
* NetBeans
* Visual Studio

An IDE provides built-in features for writing, compiling, and executing programs, reducing the need to use the command prompt separately.

## Basic Java Program Structure

A Java program can contain components such as:

* Class
* Interface

### Class

`class` is a Java keyword used to create a class.

### Syntax

```text
class ClassName
{
    // statements
}
```

Every class has:

* A class name
* A class body or block

The class body can contain members such as:

* Variables
* Methods
* Initializers

### Variable

A variable is a named memory location used to store data or values.

### Method

A method is a block of instructions used to perform a specific task.

### Initializer

An initializer is used to execute initialization instructions.

## Main Method

The main method is the entry point of a Java application.

### Syntax

```text
public static void main(String[] args)
{
    // instructions
}
```

A Java program must contain a main method to execute the application.

A class without a main method can still be compiled, but it cannot be executed as a standalone Java application.

## Java Comments

### Single-Line Comment

Syntax:

```text
// comment
```

### Multi-Line Comment

Syntax:

```text
/* comment */
```

## Printing Output

Java provides `print()` and `println()` methods for displaying output.

### `println()`

Syntax:

```text
System.out.println(Data);
```

* Prints the given data.
* Moves the cursor to the next line.
* Can also be used without passing data.

### `print()`

Syntax:

```text
System.out.print(Data);
```

* Prints the given data.
* Does not move the cursor to the next line.
* Requires data to be passed.

## Java Compiler and Execution Commands

### Compile a Java File

Syntax:

```text
javac filename.java
```

### Execute a Java Program

Syntax:

```text
java classname
```

The `javac` command invokes the Java compiler, while the `java` command is used to run the compiled Java program.
